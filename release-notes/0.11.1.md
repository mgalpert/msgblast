- Setup no longer gets stuck when an app agent fails its connection check: Continue and Skip on Connect your agents always let you finish, and you can connect that app later from Settings.
- Claude and Muse connect again on their current Mac app versions. An empty Claude chat is no longer mistaken for a draft, and Muse chats with cards, like Week ahead, no longer stall the check.
- Mac app agents no longer stay stuck on Busy. A request with no answer after 15 minutes clears itself, as if you had pressed Stop waiting, and nothing is sent again.
- ChatGPT connects and sends again on ChatGPT 26.1111, which renamed its empty message box.
- Claude also connects when its window is showing a Code session: msgblast opens a new chat for the check, and a failed check is now shown in red.
- Feedback diagnostics, when you choose to include them, now show whether Accessibility, Screen Recording, Contacts, Messages access and Automation are allowed, so setup problems are easier to diagnose. You can see exactly what is sent before you send it.
- Alexa Shopping's suggestion buttons now show under its replies on the iPhone, and tapping one taps Alexa's real button. Outside agents can see and choose them too.
