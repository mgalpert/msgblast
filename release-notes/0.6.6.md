# msgblast 0.6.6

- Keep separate comparison chats and drafts when switching comparisons, including chats sent directly in a model’s page.
- Send shared prompts with repeated spaces or line breaks to all selected web models with one click.
- Recover older unlinked chats by reviewing their existing request and reply, without resending.
- See feedback confirmation without scrolling, and clearer guidance for Messages permissions and demo agents.
- Remove the extra chat count and navigation strip from comparisons.
- Show draft-blocking guidance on shared Send instead of an always-visible chat warning.
- Send new agents only the original ask and shared follow-ups, without generated joining instructions or labels.
