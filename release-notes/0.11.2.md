- A late message from a Messages contact no longer shows up in an old, unrelated conversation. It now appears in its own thread named after that contact, and replies to a new conversation always show in that conversation.
- The Mac composer no longer freezes when you type or paste a very long message.
- On iPhone, New Conversation now lists only agents that are connected on your Mac (on its agent grid and set up there), and it updates while open as agents connect or leave.
- The Mac now limits how many uploads and requests from the iPhone it holds at once, and a send repeated after remote control restarts is never run twice.
- On iPhone, if a send times out and you send again, a late confirmation of the first send now lands on that send's own conversation instead of being lost.
