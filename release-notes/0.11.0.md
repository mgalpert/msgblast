- Let Claude Code, Codex and other agents on your Mac use msgblast through its new MCP server and `msgblast` command. They can read your agents, comparisons and replies, and wait for new replies.
- Connect Grok Bot over Tailscale, with a copyable setup block and readiness checks in Settings.
- Approve each outside agent once, as Read only or Full access, and change or remove it any time in Settings → Outside agents.

## Setup

Turn on Settings → Outside agents. Use the copy buttons there to add msgblast to Claude Code (`claude mcp add`) or Codex, or to copy the `msgblast` command's path. The first time an agent connects, msgblast asks you which level it gets. Agents can't send messages yet.

For Grok Bot, see [Connect Grok Bot](https://github.com/mgalpert/msgblast/blob/main/docs/grok-bot.md). It needs Tailscale on this Mac and Grok Bot's Tailscale plugin.
