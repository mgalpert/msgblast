- Control msgblast from your iPhone: pair a phone in Settings › Remote, then read replies and send to your agents from anywhere on your network or Tailscale tailnet.
- The Mac stays the only place that runs agents or sends iMessages; the phone is a secure remote with its own paired key.
- Keep Mac Awake from the phone holds the Mac awake while you are using the remote.
- Let Claude Code, Codex and other agents on your Mac use msgblast through its new MCP server and `msgblast` command. Read only agents see your agents, comparisons and replies, and can wait for new replies. Full access agents can also start a blast, follow up, message one agent and end a comparison.
- See each send an outside agent makes in a banner, and stop new ones with Stop Agent Sends.
- Connect Grok Bot over Tailscale, with copy buttons and readiness checks in Settings.

Remote is off until you turn it on. Pairing shows a QR code and a key fingerprint to compare; one phone is paired at a time, and Forget removes it. The phone app is distributed separately through TestFlight and needs this version or newer on the Mac.

## Outside agents

Outside agents are off until you turn on Settings → Outside agents. Use the copy buttons there to add msgblast to Claude Code (`claude mcp add`) or Codex, or to copy the `msgblast` command's path. The first time an agent connects, msgblast asks you whether it gets Read only or Full access, and you can change or remove it there later. A Full access agent can send iMessages to your contacts, so give it only to agents you trust.

For Grok Bot, see [Grok Bot over Tailscale](https://github.com/mgalpert/msgblast/blob/main/docs/grok-bot.md). It needs Tailscale on this Mac and Grok Bot's Tailscale plugin.
