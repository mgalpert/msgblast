# Onboarding feedback menu screenshot

`Onboarding/feedback-menu.png` is an unretouched native macOS screenshot of this app’s Help menu with Share Feedback… hovered and highlighted. It was captured on October 8, 2026 by `WorkflowTests.testShareFeedbackMenuIsAvailableAnytime` using an isolated demo build with `AppIconDemo` and bundle ID `com.msgblast.feedback-tip-tests`.

The 3024 × 1964 source screenshot was cropped to pixel bounds `(841, 0, 1580, 290)` to retain just the menu and its Help title. No menu text, highlight, or interface pixels were generated or altered. The macOS beta adds its own Send msgblast Feedback to Apple item above the app’s highlighted command. No feedback was submitted.
