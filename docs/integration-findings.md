## Read-only database permission gate

`sqlite3 -readonly ~/Library/Messages/chat.db` was denied with “authorization denied,” both inside and outside the Codex shell sandbox. Full Disk Access must be manually granted by the user. No live Messages schema or conversation record was copied, and no database write was attempted.

The adapter's joins and optional thread field are fixture-verified assumptions, not observations of the current live schema. It opens with `SQLITE_OPEN_READONLY | SQLITE_OPEN_FULLMUTEX`. It detects required column/table failures and blocks rather than attempting schema repair. It currently displays an explicit unavailable-body placeholder when `message.text` is absent; modern `attributedBody` decoding remains an integration gate. Do not claim complete history support until current authorized test records have been inspected.
